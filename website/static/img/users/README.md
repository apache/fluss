# User logos

Original images supplied by organizations in [Who is using Apache Fluss?](https://github.com/apache/fluss/discussions/4033). Brand marks remain the property of their respective owners.

The original submission images are used on the User Stories cards, with replacement assets and their sources noted below. Cisco supplied the Webex by Cisco lockup.

The homepage and story headers use separate white-on-transparent assets, downloaded or converted from user-supplied originals as noted below. No color filters, masks, or blend modes recolor the logos at runtime. The SVG viewport only normalizes blank or transparent padding, preserving the artwork and its aspect ratio. Logo files are stored locally so page loads do not depend on external asset hosts.

## White assets

Retrieved 2026-09-22. Downloaded files retain the bytes from their source (or the image within its archive / embedded data URL). The iQIYI SVG changes only the fill color of the user-supplied artwork to white. The rednote PNG is a white, transparent conversion of the user-supplied lockup, preserving its original pixel dimensions and contours. The homepage uses the Cisco company mark for the Cisco Webex story; its submitted Webex lockup remains on the User Stories cards.
